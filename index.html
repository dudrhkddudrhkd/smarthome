제작자: yejin
ESP32 블루투스 모듈과 페어링하여
실시간 홈 제어 시스템을 시작하세요.

💡 안내: 본 앱은 HTTPS 환경 또는 localhost에서 작동합니다.
아이폰 사용자는 App Store에서 Bluefy 앱을 이용하세요.

🔍 페어링이 안 될 때 체크리스트: 1. ESP32 보드에 전원이 켜져 있고 파이썬 코드가 실행 중인지 확인
2. PC 또는 스마트폰의 Bluetooth가 활성화되어 있는지 확인
3. ESP32 기기가 다른 기기(스마트폰 등)나 다른 웹 탭에 이미 연결되어 있는지 확인 (BLE는 1:1 연결만 가능)
4. 주소창 주소가 http://localhost:8080 또는 https://... 로 시작하는지 확인 (보안 컨텍스트 필수)
